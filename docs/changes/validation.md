# Проверка исправленного комплекта

Исходный общий draw.io содержит 626 элементов (mxCell и UserObject); все они сохранены. Изменены подписи 5 исходных элементов Use Case/Activity и рамка с 5 линиями жизни Sequence. Добавлены два прецедента заказчика, два примечания и продолжение исходной последовательности. Компоненты и шесть исходных макетов совпадают с предоставленным XML. Новые отдельные диаграммы исключены.

В отдельной локальной копии воспроизведены базовый коммит и три коммита iteration-1-docs. Рабочее дерево чистое; git diff --check main...HEAD не находит ошибок пробелов. Проверены 20 локальных ссылок и наличие 11 операций OpenAPI. Скрипт исправления проверяет хеши 18 ошибочно добавленных файлов и создаёт резервную копию перед заменой.

Отчёт DOCX отрисован и просмотрен на всех трёх страницах; титульный лист, шрифты, поля и колонтитул сохранены по 2_3.docx. Единый PDF содержит 24 страниц, оглавление из 7 разделов и сквозные номера страниц. Диаграммы в актуальных PDF основаны на исходных работах 3–4. Расширения данных перечислены отдельно от исходных ER-рисунков и согласованы с schema.sql.

Проверки относятся к подготовленным файлам. В пользовательском GitHub исходный коммит 5be551b отправлен пользователем; фиксация итерации и создание PR ещё предстоят. Полноценное приложение не реализовано, испытания backend и применение DDL к рабочей базе не заявляются. Сценарии учебного HTML-макета нужно просмотреть в браузере перед сдачей.
